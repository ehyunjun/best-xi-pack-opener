# Best XI Pack Opener

축구 카드팩을 개봉해 선수 카드를 수집하고, 나만의 Best XI 스쿼드를 구성하는 웹 프로젝트입니다.

## 주요 기능

- 카드팩 보관함 화면
- 카드팩 상점 화면
- 선수 카드 보관함 화면
- Best XI 스쿼드 빌더 화면
- 저장한 스쿼드를 볼 수 있는 갤러리 화면
- 스쿼드 상세 화면

## 게임 규칙

- 사용자는 카드팩을 통해 선수 카드를 수집합니다.
- 수집한 선수 카드로 포지션에 맞는 Best XI 스쿼드를 구성합니다.
- 완성한 스쿼드는 갤러리에 저장해 다시 확인할 수 있습니다.
- 카드팩 개봉, 상점, 저장 기능은 이후 단계에서 구현합니다.

## 기술 스택

- Vite
- React
- React Router
- JavaScript
- CSS

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버가 실행되면 터미널에 표시되는 로컬 주소로 접속합니다.

## 구현 예정 기능

- 카드팩 개봉 애니메이션과 결과 화면
- 선수 카드 데이터와 등급 시스템
- 카드팩 구매 및 보상 시스템
- 카드 보관함 필터와 정렬
- 스쿼드 편성, 저장, 불러오기
- `localStorage` 기반 로컬 저장
